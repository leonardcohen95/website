闯关地图

    LCEL 表达式语言

    LCEL（LangChain Expression Language）是 LangChain 的声明式组合语言，用管道符 | 将组件组合成链。它是新版 LangChain 的推荐写法，原生支持流式、异步、并行、可观测性。

    学习目标

    • 用 | 操作符组合 Runnable 组件
    • 理解 Runnable 接口（invoke、stream、batch）
    • 使用 RunnableLambda、RunnablePassthrough、RunnableParallel
    • 掌握 bind、with_config、with_fallback 等方法

    1. 基础组合

    from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

prompt = ChatPromptTemplate.from_template("用{style}的风格解释{topic}")
llm = ChatOpenAI()
parser = StrOutputParser()

chain = prompt | llm | parser
result = chain.invoke({"style": "简洁", "topic": "RAG"})
print(result)

    2. Runnable 接口方法

    • invoke(input)：同步执行，返回结果
    • stream(input)：流式输出，返回迭代器
    • batch(inputs)：批量执行多个输入
    • ainvoke / astream / abatch：异步版本

    3. RunnableLambda

    将普通函数包装为 Runnable：

    from langchain_core.runnables import RunnableLambda

def upper_case(text):
    return text.upper()

runnable = RunnableLambda(upper_case)
chain = prompt | llm | parser | runnable

    4. RunnablePassthrough

    将输入原样传递，常用于保留原始输入：

    from langchain_core.runnables import RunnablePassthrough

chain = {
    "question": RunnablePassthrough(),
    "context": retriever,
} | prompt | llm | parser

    5. 并行执行

    用字典语法实现并行：

    parallel = {
    "translation": translate_chain,
    "summary": summary_chain,
}
result = parallel.invoke("你好世界")
# result = {"translation": "...", "summary": "..."}

    6. 实用方法

    • .bind(stop=["\n"])：绑定额外参数（如停止词、tools）
    • .with_config(tags=["debug"])：配置 tags、metadata 等
    • .with_fallback(fallback_chain)：主链失败时切换到备用链
    • .with_retry(stop_after_attempt=3)：失败重试
    from langchain_core.runnables import RunnableBranch

branch = RunnableBranch(
    (lambda x: "数学" in x["topic"], math_chain),
    (lambda x: "物理" in x["topic"], physics_chain),
    general_chain  # 默认分支
)
    💡 为什么用 LCEL

    1. 原生支持流式输出和异步
    2. 自动集成 LangSmith 追踪
    3. 支持并行、分支、重试、降级
    4. 组合灵活，代码更简洁

    本章小结

    • LCEL 用 | 组合 Runnable，是新版推荐写法
    • Runnable 支持 invoke、stream、batch 及异步版本
    • RunnableLambda 包装函数，RunnablePassthrough 透传输入
    • 字典语法实现并行，RunnableBranch 实现条件分支
    • bind、with_config、with_fallback、with_retry 提供高级控制
