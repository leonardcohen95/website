    向量数据库与 Embeddings

    要实现语义搜索和 RAG，核心是将文本转换为向量（Embedding），并存入向量数据库进行相似度检索。本章学习 Embedding 原理和常见向量数据库。

    学习目标

    • 理解 Embedding 的原理和作用
    • 使用 OpenAIEmbeddings 生成向量
    • 掌握常见向量数据库（Chroma、FAISS、Pinecone）
    • 实现向量存储和相似度搜索

    1. Embedding 是什么

    Embedding 将文本转换为高维向量（如 1536 维）。语义相近的文本，在向量空间中的距离也相近。这使得"语义搜索"成为可能——不依赖关键词匹配，而是理解文本含义。

    💡 重要原则

    查询文本和文档必须用同一个 embedding 模型生成向量，才能在同一向量空间中比较相似度。

    2. 使用 OpenAIEmbeddings

    from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 生成文本向量
vectors = embeddings.embed_documents(["你好", "世界和平", "机器学习"])
query_vec = embeddings.embed_query("人工智能")

    text-embedding-3-small 输出 1536 维向量，也可用 dimensions 参数降维。

    3. 常见向量数据库

    🟢 Chroma

    轻量级本地向量数据库，易于集成，适合开发和原型。

    🔍 FAISS

    Facebook 开源的向量相似度搜索库，本地高效检索，适合大规模数据。

    🌲 Pinecone

    托管式云向量数据库服务，支持大规模、高可用，生产环境常用。

    4. 存入向量数据库并检索

    from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings

# 从文档创建向量库
vectorstore = Chroma.from_documents(
    documents=chunks,
    embedding=OpenAIEmbeddings(),
    persist_directory="./chroma_db"
)

# 相似度搜索
results = vectorstore.similarity_search("如何申请退款", k=3)
for doc in results:
    print(doc.page_content)

    5. 相似度度量

    • 余弦相似度（Cosine Similarity）：衡量向量方向的夹角，最常用，值越接近 1 越相似
    • 欧氏距离（L2 Distance）：向量间的直线距离
    • 内积（Dot Product）：向量点积

    本章小结

    • Embedding 将文本转为高维向量，语义相近则向量相近
    • 查询和文档必须用同一 embedding 模型
    • 常见向量库：Chroma（本地轻量）、FAISS（本地高效）、Pinecone（云服务）
    • 用 from_documents 创建向量库，similarity_search 检索
