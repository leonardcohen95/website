闯关地图

    LangChain 是什么

    大语言模型（LLM）的爆发让 AI 应用开发进入了新纪元。但直接调用 LLM API 只能完成最简单的对话，要构建真正有用的应用——比如智能客服、知识库问答、数据分析助手——你需要把 LLM 和外部数据、工具、记忆系统组合起来。LangChain 就是为此而生的开发框架，它提供了一套标准化的组件，帮你快速搭建复杂的 LLM 应用。

    学习目标

    • 理解 LangChain 的定位和核心价值
    • 了解 LangChain 的核心模块
    • 知道 LangChain 能做什么、不能做什么
    • 了解 LangChain 生态（LangSmith、LangGraph、LangServe）

    1. 为什么需要 LangChain

    直接调用 LLM API（如 OpenAI 的 chat.completions）只能做到"一问一答"。但现实中的 LLM 应用需要更多能力：

    • 连接外部知识：让 LLM 基于你的私有文档回答，而不是只靠训练数据
    • 使用工具：让 LLM 调用搜索、计算器、数据库等外部功能
    • 保持记忆：在多轮对话中记住之前说过的话
    • 链式编排：把多个步骤组合成一个完整的工作流

    LangChain 把这些能力封装成标准化的组件，让开发者像搭积木一样构建 LLM 应用，而不必从零实现每个环节。

    2. LangChain 的核心模块

    📝 Models（模型）

    封装各种 LLM 的调用接口，支持 OpenAI、Anthropic、HuggingFace 等，屏蔽不同 API 的差异。

    ✍️ Prompts（提示词）

    提供 PromptTemplate、FewShotPrompt、OutputParser 等，管理和复用提示词，将输出解析为结构化数据。

    ⛓️ Chains（链）

    将 Prompt、LLM、Parser 等组件串联起来，形成可复用的处理流程，是 LangChain 的核心编排单元。

    🧠 Memory（记忆）

    在多次调用间保持上下文，支持 Buffer、Summary、Entity 等多种记忆策略。

    🔍 Retrievers（检索器）

    从向量数据库等数据源中检索相关文档，是 RAG（检索增强生成）的关键组件。

    🤖 Agents（智能体）

    让 LLM 自主决策调用哪些工具、以什么顺序执行，完成复杂的多步任务。

    3. LangChain 生态

    LangChain 不只是一个框架，而是一个完整的生态：

    🔎 LangSmith

    可观测性平台，用于调试、监控和评估 LLM 应用，记录每次调用的输入输出。

    🕸️ LangGraph

    用于构建有状态的、多 Agent 协作的复杂工作流，支持循环和条件分支。

    🚀 LangServe

    将 LangChain 链快速部署为 REST API，支持流式输出。

    4. 谁在使用 LangChain

    LangChain 被广泛用于：

    • 企业内部知识库问答系统
    • 智能客服与对话机器人
    • 代码辅助开发工具
    • 数据分析与报告生成
    • 文档摘要与信息提取
    • 自动化 Agent（研究、写作、运营）
    💡 给初学者的话

    不要把 LangChain 想得太复杂。它本质上就是一套"LLM 应用的乐高积木"：你用 Prompt 告诉 LLM 做什么，用 Chain 把步骤连起来，用 Memory 记住上下文，用 Retriever 接上外部知识，用 Agent 让它自己干活。跟着本课程一章一章学，你就能从零搭建出能上线的 LLM 应用。

    本章小结

    • LangChain 是构建 LLM 应用的开发框架，核心价值是"链式编排 + 组件复用"
    • 核心模块：Models、Prompts、Chains、Memory、Retrievers、Agents
    • 生态：LangSmith（监控）、LangGraph（多Agent）、LangServe（部署）
    • 应用场景：知识库问答、智能客服、代码辅助、数据分析等
