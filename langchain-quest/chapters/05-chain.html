    Chain 链式调用

    Chain 是 LangChain 的核心编排单元，它将 Prompt、LLM、Parser 等组件链接在一起，形成完整的处理流程。本章学习各种 Chain 类型以及新版 LCEL 的组合方式。

    学习目标

    • 理解 LLMChain 的组成和用法
    • 掌握 SequentialChain 串联多个链
    • 了解 RouterChain 动态路由
    • 用 LCEL 的 | 操作符组合组件

    1. LLMChain：最基本的链

    LLMChain = PromptTemplate + LLM +（可选）OutputParser：

    from langchain.chains import LLMChain
from langchain_core.prompts import PromptTemplate

prompt = PromptTemplate.from_template("将以下句子翻译为{lang}：{text}")
chain = LLMChain(llm=llm, prompt=prompt)
result = chain.invoke({"lang": "英文", "text": "你好世界"})
print(result["text"])

    2. LCEL：新版推荐写法

    LangChain 0.2+ 推荐用 LCEL（LangChain Expression Language）的 | 操作符组合组件：

    from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser

prompt = PromptTemplate.from_template("将以下句子翻译为{lang}：{text}")
chain = prompt | llm | StrOutputParser()
result = chain.invoke({"lang": "英文", "text": "你好世界"})
print(result)

    LCEL 原生支持流式输出（.stream()）、异步（.ainvoke()）、并行、LangSmith 追踪等。

    3. SequentialChain：串联多个链

    SimpleSequentialChain 将多个链按顺序串联，前一个输出作为后一个输入：

    from langchain.chains import SimpleSequentialChain

chain1 = LLMChain(llm=llm, prompt=prompt1)  # 翻译为英文
chain2 = LLMChain(llm=llm, prompt=prompt2)  # 对英文结果做摘要
full_chain = SimpleSequentialChain(chains=[chain1, chain2])
result = full_chain.invoke("你好世界")

    如果需要传递多个变量，用 SequentialChain，显式声明每个链的 input_keys 和 output_keys。

    4. RouterChain：动态路由

    RouterChain 根据输入内容动态选择最合适的子链处理：

    from langchain.chains.router import MultiPromptChain

physics_template = "你是物理老师。问题：{input}"
math_template = "你是数学老师。问题：{input}"

prompt_infos = [
    {"name": "physics", "description": "适合回答物理问题", "prompt_template": physics_template},
    {"name": "math", "description": "适合回答数学问题", "prompt_template": math_template},
]
chain = MultiPromptChain.from_prompts(llm, prompt_infos)

    5. 用 LCEL 实现并行

    用字典语法实现多个 Runnable 并行执行：

    from langchain_core.runnables import RunnablePassthrough

parallel_chain = {
    "translation": translate_chain,
    "summary": summary_chain,
    "original": RunnablePassthrough()
}
result = parallel_chain.invoke("你好世界")

    本章小结

    • LLMChain = Prompt + LLM + Parser，是最基本的链
    • LCEL 用 | 操作符组合组件，推荐替代传统 Chain
    • SequentialChain 按顺序串联多个链
    • RouterChain 根据输入动态路由到不同子链
