    多模态与流式输出

    现代 LLM 不仅能处理文本，还能理解图像（多模态）；流式输出让用户实时看到生成过程。本章学习这两个实用特性。

    学习目标

    • 理解多模态 LLM 的概念
    • 在 LangChain 中传入图片让 LLM 理解
    • 使用流式输出提升用户体验
    • 了解异步流式处理

    1. 多模态 LLM

    多模态模型（如 GPT-4V、Claude 3、Gemini）能同时理解文本和图像。LangChain 通过在 HumanMessage 的 content 中传入 image_url 来支持。

    2. 传入图片

    from langchain_core.messages import HumanMessage
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o")

message = HumanMessage(
    content=[
        {"type": "text", "text": "这张图片里有什么？"},
        {"type": "image_url", "image_url": {"url": "https://example.com/image.jpg"}},
    ]
)
response = llm.invoke([message])
print(response.content)

    图片可以是 URL，也可以是 base64 编码：

    import base64
with open("image.png", "rb") as f:
    img_b64 = base64.b64encode(f.read()).decode()
message = HumanMessage(content=[
    {"type": "text", "text": "描述这张图片"},
    {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{img_b64}"}}
])

    3. 流式输出

    用 .stream() 方法逐步获取 LLM 输出：

    for chunk in chain.stream({"topic": "RAG"}):
    print(chunk, end="", flush=True)

    每个 chunk 是生成的一小段文本，实时打印出来，用户体验更好。

    4. 异步流式

    async for chunk in chain.astream({"topic": "RAG"}):
    print(chunk, end="", flush=True)

    5. 多模态应用场景

    • 图片描述生成（为图片生成文字说明）
    • 图表数据分析（让 LLM 解读图表）
    • 文档 OCR 问答（上传文档图片进行问答）
    • 界面理解与自动化（理解 UI 截图并操作）

    6. 音频处理

    LangChain 本身不直接处理音频，通常先用 Whisper 等语音识别模型将音频转为文字，再交给 LLM 处理：

    # 用 OpenAI Whisper 转写音频
from openai import OpenAI
client = OpenAI()
transcript = client.audio.transcriptions.create(
    model="whisper-1", file=open("audio.mp3", "rb")
)
print(transcript.text)

    本章小结

    • 多模态 LLM 能理解文本和图像，通过 image_url 传入图片
    • 图片可用 URL 或 base64 编码
    • .stream() 流式输出，实时展示生成过程
    • 音频先用 Whisper 转文字再处理
