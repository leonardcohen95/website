    工具与函数调用

    工具（Tool）是 Agent 与外部世界交互的接口。本章学习如何定义、使用工具，以及 Function Calling 的原理。

    学习目标

    • 使用 @tool 装饰器和 Tool 类定义工具
    • 使用 StructuredTool 处理多参数输入
    • 理解 Function Calling 的工作原理
    • 了解常用内置工具

    1. 定义工具

    用 @tool 装饰器最简单，函数名成为工具名，docstring 成为描述：

    from langchain_core.tools import tool

@tool
def calculator(expression: str) -> str:
    """计算数学表达式并返回结果。expression 是一个合法的 Python 数学表达式字符串。"""
    try:
        return str(eval(expression))
    except:
        return "计算错误"

print(calculator.name)      # calculator
print(calculator.description)  # docstring

    2. StructuredTool：多参数输入

    当工具需要多个结构化参数时，用 StructuredTool + Pydantic：

    from langchain_core.tools import StructuredTool
from pydantic import BaseModel

class WeatherInput(BaseModel):
    city: str
    unit: str = "celsius"

def get_weather(city: str, unit: str = "celsius") -> str:
    return f"{city}今天天气晴，25度{unit}"

weather_tool = StructuredTool.from_function(
    func=get_weather,
    name="get_weather",
    description="获取指定城市的天气",
    args_schema=WeatherInput
)

    3. Function Calling 原理

    Function Calling 不是让 LLM 直接执行函数，而是：

    1. 程序将函数名、参数描述、函数说明传给 LLM
    2. LLM 判断需要调用哪个函数，并输出结构化的函数名和参数
    3. 程序接收后实际执行函数
    4. 将执行结果返回 LLM，LLM 继续生成最终回答

    LangChain 的 Agent 内部就封装了这个流程。

    4. 常用内置工具

    • SerpAPI / TavilySearch：网络搜索
    • PythonREPL：执行 Python 代码（计算、数据处理）
    • SQLDatabase：查询 SQL 数据库
    • Retriever：作为工具封装的文档检索
    • requests：发送 HTTP 请求

    5. 工具使用最佳实践

    • description 要清晰准确，帮助 LLM 正确选择工具
    • 参数用 Pydantic 模型定义，带 description 说明每个字段
    • 做好错误处理，工具失败时返回有意义的错误信息
    • return_direct=True 可让工具结果直接返回用户，不经 LLM 再处理

    本章小结

    • @tool 装饰器快速定义工具，docstring 作为描述
    • StructuredTool 支持多参数结构化输入
    • Function Calling：LLM 输出函数名和参数，程序执行后返回结果
    • 常用工具：搜索、PythonREPL、SQLDatabase、Retriever
