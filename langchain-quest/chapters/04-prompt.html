    Prompt 工程

    Prompt 是人与 LLM 沟通的桥梁。好的 Prompt 能让 LLM 输出高质量、结构化的结果；差的 Prompt 则会得到模糊、无用的回答。本章学习 LangChain 中 Prompt 的管理与解析。

    学习目标

    • 使用 PromptTemplate 创建可复用的提示模板
    • 使用 FewShotPromptTemplate 提供示例
    • 使用 OutputParser 将输出解析为结构化数据
    • 掌握 ChatPromptTemplate 构建对话模板

    1. PromptTemplate

    PromptTemplate 用 {variable} 语法定义带变量的模板，调用时传入具体值：

    from langchain_core.prompts import PromptTemplate

template = PromptTemplate.from_template(
    "你是一个{role}。请用{style}的风格解释{concept}。"
)
prompt = template.format(role="编程导师", style="简洁", concept="RAG")
print(prompt)

    输出：你是一个编程导师。请用简洁的风格解释RAG。

    2. FewShotPromptTemplate

    给模型提供几个示例（few-shot），引导它按期望的格式输出：

    from langchain_core.prompts import FewShotPromptTemplate, PromptTemplate

examples = [
    {"input": "开心", "output": "😊"},
    {"input": "难过", "output": "😢"},
]
example_prompt = PromptTemplate.from_template("输入：{input}\n输出：{output}")

few_shot = FewShotPromptTemplate(
    examples=examples,
    example_prompt=example_prompt,
    suffix="输入：{emotion}\n输出：",
    input_variables=["emotion"]
)
print(few_shot.format(emotion="愤怒"))

    3. OutputParser

    LLM 输出是文本，OutputParser 将其解析为结构化数据：

    📋 CommaSeparatedListOutputParser

    将输出解析为逗号分隔的列表。

    📐 PydanticOutputParser

    基于 Pydantic 模型解析为强类型对象，支持嵌套结构，是最强大的 Parser。

    from langchain_core.output_parsers import PydanticOutputParser
from pydantic import BaseModel, Field

class Movie(BaseModel):
    title: str = Field(description="电影名")
    year: int = Field(description="上映年份")
    genre: list[str] = Field(description="类型列表")

parser = PydanticOutputParser(pydantic_object=Movie)
prompt = PromptTemplate.from_template(
    "推荐一部电影。\n{format_instructions}\n电影：{query}"
)
chain = prompt | llm | parser
result = chain.invoke({"query": "科幻片", "format_instructions": parser.get_format_instructions()})
print(result.title, result.year, result.genre)

    4. ChatPromptTemplate

    用于构建聊天消息列表，支持消息占位符：

    from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个{role}。"),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{question}")
])
    💡 Prompt 编写原则

    1. 明确角色设定（SystemMessage）
    2. 清楚描述任务和要求
    3. 给出期望的输出格式
    4. 提供示例（few-shot）效果更好
    5. 避免模糊和歧义的表达

    本章小结

    • PromptTemplate 用 {variable} 创建可复用模板
    • FewShotPromptTemplate 通过示例引导输出格式
    • OutputParser 将文本输出解析为结构化数据（PydanticOutputParser 最强）
    • ChatPromptTemplate 构建对话消息模板，MessagesPlaceholder 占位历史消息
