闯关地图

    环境搭建与首个调用

    本章我们动手搭建 LangChain 开发环境，并完成第一次 LLM 调用。工欲善其事，必先利其器，一个干净、可复用的环境是高效开发的基础。

    学习目标

    • 搭建 Python 虚拟环境并安装 LangChain
    • 配置 LLM API Key
    • 完成第一次 LLM 调用
    • 理解新版 LangChain 的包结构

    1. 环境准备

    推荐使用 Python 3.10+（LangChain 0.2+ 支持 3.8.1+，但生产建议 3.10/3.11）。创建虚拟环境可以隔离项目依赖，避免污染系统 Python。

    # 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# macOS / Linux:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# 升级 pip
pip install --upgrade pip

    2. 安装 LangChain

    新版 LangChain（0.2+）将核心和第三方集成拆分到不同的包中，结构更清晰：

    # 核心包（包含 Chains、Agents、Memory 等）
pip install langchain

# OpenAI 集成
pip install langchain-openai

# 社区集成（包含大量第三方工具、向量库等）
pip install langchain-community

# 核心抽象（通常作为依赖自动安装）
pip install langchain-core
    💡 包结构说明

    langchain-core：核心抽象（Runnable、BaseLLM 等）
    langchain：核心功能（Chains、Agents、Memory）
    langchain-community：社区贡献的第三方集成
    langchain-openai、langchain-anthropic 等：各模型厂商的独立集成包

    3. 配置 API Key

    LLM 服务需要 API Key 才能调用。推荐用 .env 文件管理密钥，避免硬编码。

    # 安装 python-dotenv
pip install python-dotenv

    在项目根目录创建 .env 文件：

    # .env 文件内容
OPENAI_API_KEY=sk-your-api-key-here
    ⚠️ 安全提醒

    绝不要把 API Key 硬编码在代码中，也不要提交到 Git 仓库。务必将 .env 加入 .gitignore。

    4. 第一次 LLM 调用

    一切就绪，让我们写第一个 LangChain 程序：

    from dotenv import load_dotenv
load_dotenv()  # 加载 .env 中的环境变量

from langchain_openai import ChatOpenAI

# 初始化聊天模型
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0.7)

# 调用模型
response = llm.invoke("用一句话解释什么是 LangChain")
print(response.content)

    运行后你会看到类似输出：

    LangChain 是一个用于构建基于大语言模型应用的开发框架，它提供了链式调用、记忆、检索等组件，帮助开发者快速搭建复杂的 LLM 应用。

    5. 使用消息格式调用

    实际开发中，我们通常用消息列表（SystemMessage、HumanMessage、AIMessage）来组织对话：

    from langchain_core.messages import SystemMessage, HumanMessage

messages = [
    SystemMessage(content="你是一个专业的编程导师，回答要简洁准确。"),
    HumanMessage(content="什么是 LangChain？")
]

response = llm.invoke(messages)
print(response.content)

    6. 验证安装

    python -c "import langchain; print(langchain.__version__)"

    能正常输出版本号说明安装成功。

    本章小结

    • 使用虚拟环境隔离依赖，安装 langchain、langchain-openai、langchain-community
    • 用 .env 文件管理 API Key，配合 python-dotenv 加载
    • ChatOpenAI 是新版推荐的聊天模型类，通过 .invoke() 调用
    • 用 SystemMessage/HumanMessage/AIMessage 组织对话消息
