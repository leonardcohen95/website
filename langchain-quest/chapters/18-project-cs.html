    实战：智能客服机器人

    本章综合运用前面所学，从零构建一个具备多轮对话和知识库问答能力的智能客服机器人。

    学习目标

    • 整合 RAG + Memory 构建客服系统
    • 实现意图识别和多轮对话
    • 添加工具调用（查询订单、转人工）
    • 用 LangServe 部署客服 API

    1. 项目架构

    智能客服核心能力：

    • FAQ 问答：基于知识库回答常见问题
    • 多轮对话：记住上下文，理解指代
    • 意图识别：区分咨询、投诉、查订单等意图
    • 工具调用：查询订单、转人工客服等操作

    2. 构建知识库

    from langchain_community.document_loaders import TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings

loader = TextLoader("faq.txt")
docs = loader.load()
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(docs)
vectorstore = Chroma.from_documents(chunks, OpenAIEmbeddings(), persist_directory="./cs_db")
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})

    3. 定义工具

    from langchain_core.tools import tool

@tool
def query_order(order_id: str) -> str:
    """根据订单号查询订单状态。order_id 是订单编号。"""
    # 实际项目中查数据库
    return f"订单 {order_id} 状态：已发货，预计明天送达"

@tool
def transfer_to_human(reason: str) -> str:
    """转接人工客服。reason 是转接原因。"""
    return f"已为您转接人工客服，原因：{reason}，请稍候..."

tools = [query_order, transfer_to_human]

    4. 组装客服 Agent

    from langchain.agents import AgentExecutor, create_openai_tools_agent
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.chat_history import InMemoryChatMessageHistory
from langchain_core.runnables.history import RunnableWithMessageHistory

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个专业的电商客服。用中文回答，语气友好。
"
               "如果用户问常见问题，请基于知识库回答。
"
               "如果用户要查订单，使用 query_order 工具。
"
               "如果用户要求人工或问题无法解决，使用 transfer_to_human。"),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{input}"),
    MessagesPlaceholder(variable_name="agent_scratchpad"),
])

agent = create_openai_tools_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

store = {}
def get_history(session_id):
    if session_id not in store:
        store[session_id] = InMemoryChatMessageHistory()
    return store[session_id]

agent_with_history = RunnableWithMessageHistory(
    agent_executor,
    get_history,
    input_messages_key="input",
    history_messages_key="history",
)

    5. 整合 RAG 知识

    将检索器作为工具加入 Agent，让 Agent 自主决定是否查询知识库：

    from langchain.tools.retriever import create_retriever_tool

retriever_tool = create_retriever_tool(
    retriever,
    name="faq_search",
    description="搜索常见问题知识库，回答用户咨询"
)
tools.append(retriever_tool)

    6. 部署为 API

    from langserve import add_routes
from fastapi import FastAPI

app = FastAPI(title="智能客服")
add_routes(app, agent_with_history, path="/customer-service")
