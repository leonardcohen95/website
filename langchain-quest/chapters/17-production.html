    生产部署

    从原型到生产，需要关注异步并发、缓存、限流、部署等工程问题。本章学习如何将 LangChain 应用稳定、高效地部署上线。

    学习目标

    • 使用异步调用提升并发性能
    • 理解缓存机制减少重复调用
    • 掌握限流和降级策略
    • 用 LangServe 将链部署为 API

    1. 异步调用

    LLM API 调用通常较慢（几秒），同步调用会阻塞线程。用异步方法可大幅提升并发：

    import asyncio

async def main():
    result = await chain.ainvoke({"topic": "RAG"})
    print(result)

asyncio.run(main())

    所有 Runnable 都支持异步版本：ainvoke、astream、abatch。

    2. 批量处理

    用 batch 一次处理多个输入，减少网络开销：

    results = chain.batch([
    {"topic": "RAG"},
    {"topic": "Agent"},
    {"topic": "Memory"},
])

    3. 缓存

    对相同输入缓存 LLM 输出，避免重复调用，降低费用和延迟：

    from langchain.cache import InMemoryCache
from langchain.globals import set_llm_cache

set_llm_cache(InMemoryCache())

# 第二次相同输入会从缓存读取
result1 = chain.invoke({"topic": "RAG"})
result2 = chain.invoke({"topic": "RAG"})  # 命中缓存，不调用 API

    生产环境可用 Redis 缓存（RedisCache），支持多实例共享。

    4. 限流与降级

    • 限流（Rate Limiting）：控制请求速率，防止超出 API 配额或触发封禁
    • 重试（Retry）：网络抖动或 429 错误时自动重试，with_retry
    • 降级（Fallback）：主模型不可用时切换到备用模型，with_fallback
    chain = prompt | llm.with_retry(stop_after_attempt=3).with_fallback(fallback_llm)

    5. LangServe 部署为 API

    LangServe 可将 LangChain 链快速部署为 REST API，支持流式输出：

    from langserve import add_routes
from fastapi import FastAPI

app = FastAPI()
add_routes(app, chain, path="/chat")

# uvicorn server:app --host 0.0.0.0 --port 8000

    客户端调用：POST /chat/invoke 或 POST /chat/stream。

    6. 容器化部署

    用 Docker 打包应用，便于部署和扩展：

    FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["uvicorn", "server:app", "--host", "0.0.0.0", "--port", "8000"]

    7. 生产环境检查清单

    • ✅ 异步调用和批量处理，提升并发
    • ✅ 缓存重复请求，降低成本
    • ✅ 限流、重试、降级，保障稳定性
    • ✅ LangSmith 监控，追踪错误和性能
    • ✅ 容器化部署，便于扩展
    • ✅ 密钥管理（不用硬编码 API Key）

    本章小结

    • 异步调用（ainvoke/astream）提升并发性能
    • 缓存减少重复 LLM 调用，降低成本
    • 限流、重试、降级保障服务稳定
    • LangServe 一键将链部署为 REST API
    • 容器化部署便于扩展和运维
