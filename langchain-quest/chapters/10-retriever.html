    检索器 Retriever

    检索质量直接决定 RAG 系统的上限。本章学习各种高级检索策略，提升检索的精准度和召回率。

    学习目标

    • 理解 Retriever 接口和基础用法
    • 掌握 MMR、MultiQuery 等高级检索策略
    • 了解重排序（Rerank）和混合检索
    • 使用 ContextualCompressionRetriever 压缩结果

    1. Retriever 基础

    Retriever 的核心方法是 get_relevant_documents(query)，返回相关的 Document 列表。最常用的是从 VectorStore 创建：

    retriever = vectorstore.as_retriever(
    search_type="similarity",  # 或 "mmr"
    search_kwargs={"k": 4}
)
docs = retriever.invoke("用户问题")

    2. MMR 检索

    MMR（Maximal Marginal Relevance）在相关性和多样性之间平衡，避免返回内容高度重复的文档：

    retriever = vectorstore.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 4, "fetch_k": 20, "lambda_mult": 0.5}
)

    lambda_mult 越小越注重多样性，越大越注重相关性。

    3. MultiQueryRetriever

    用 LLM 从不同角度生成多个查询，分别检索后合并，提升召回率：

    from langchain.retrievers import MultiQueryRetriever

retriever = MultiQueryRetriever.from_llm(
    retriever=vectorstore.as_retriever(),
    llm=llm
)

    4. 重排序（Rerank）

    先用向量检索召回较多候选文档，再用更强的模型（如 Cohere Rerank、bge-reranker）重新打分排序，提升精度：

    from langchain.retrievers import ContextualCompressionRetriever
from langchain.retrievers.document_compressors import CohereRerank

compressor = CohereRerank(top_n=3)
retriever = ContextualCompressionRetriever(
    base_compressor=compressor,
    base_retriever=vectorstore.as_retriever(search_kwargs={"k": 20})
)

    5. ContextualCompressionRetriever

    用 LLM 或 embedding 对检索结果进行压缩，只保留与查询最相关的片段，减少噪声和 token 消耗。

    6. EnsembleRetriever 混合检索

    结合关键词检索（BM25）和向量检索，取长补短：

    from langchain.retrievers import EnsembleRetriever
from langchain_community.retrievers import BM25Retriever

bm25_retriever = BM25Retriever.from_documents(chunks)
vector_retriever = vectorstore.as_retriever()

ensemble = EnsembleRetriever(
    retrievers=[bm25_retriever, vector_retriever],
    weights=[0.5, 0.5]
)

    7. ParentDocumentRetriever

    将文档切成小 chunk 用于精确检索，但返回该 chunk 所属的完整父文档，兼顾检索精度和上下文完整性。

    💡 检索优化策略

    1. 调整 chunk_size 和 k 值
    2. 使用 MMR 增加多样性
    3. MultiQuery 提升召回
    4. Rerank 提升精度
    5. 混合检索兼顾关键词和语义
    6. ParentDocument 兼顾精度和上下文

    本章小结

    • Retriever 通过 get_relevant_documents 检索相关文档
    • MMR 平衡相关性和多样性，MultiQuery 从多角度检索
    • Rerank 用强模型重新排序提升精度
    • EnsembleRetriever 混合关键词和向量检索
    • ParentDocumentRetriever 检索小块但返回完整父文档
