闯关地图

    Agent 智能体

    Chain 是固定的执行流程，而 Agent 能自主决策：它根据任务，自己决定调用哪些工具、以什么顺序执行、观察结果后再决定下一步。这让 LLM 应用能完成复杂的多步任务。

    学习目标

    • 理解 Agent 的核心思想和 ReAct 模式
    • 使用 AgentExecutor 运行 Agent
    • 了解常见的 Agent 类型
    • 认识 LangGraph 用于复杂 Agent 工作流

    1. Agent 是什么

    Agent = LLM（大脑）+ Tools（手脚）。LLM 负责思考和决策，Tools 负责执行具体操作。Agent 会循环执行"思考→行动→观察"直到完成任务。

    2. ReAct 模式

    ReAct = Reasoning（推理）+ Acting（行动）。Agent 的典型循环：

    1. Thought：思考当前该做什么
    2. Action：选择并调用一个工具
    3. Observation：获取工具返回结果
    4. 重复以上步骤，直到给出最终答案

    3. 创建 Agent

    from langchain.agents import AgentExecutor, create_react_agent
from langchain_core.prompts import ChatPromptTemplate
from langchain_community.tools import SerpAPIWrapper

# 定义工具
search = SerpAPIWrapper()
tools = [search]

# 创建 Agent
prompt = ChatPromptTemplate.from_template("""Answer the following questions as best you can.
You have access to the following tools:
{tools}
Use the following format:
Question: {input}
Thought: you should always think about what to do
Action: the action to take, should be one of [{tool_names}]
Action Input: the input to the action
Observation: the result of the action
... (this Thought/Action/Action Input/Observation can repeat N times)
Thought: I now know the final answer
Final Answer: the final answer to the original input question
Begin!
{agent_scratchpad}""")

agent = create_react_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True, max_iterations=5)
result = executor.invoke({"input": "今天北京天气怎么样？"})

    4. 常见 Agent 类型

    ⚡ zero-shot-react-description

    不需要示例，直接根据工具描述决定如何使用。最常用。

    📋 react-docstore

    结合文档存储的 Agent，适合需要查阅大量文档的任务。

    ❓ self-ask-with-search

    Agent 自己拆解问题，逐个搜索子问题的答案。

    5. 关键参数

    • max_iterations：最大思考-行动循环次数，防止无限循环
    • early_stopping_method：达到最大迭代时的处理方式（generate 让 LLM 生成最终答案）
    • handle_parsing_errors：解析错误时让 LLM 自行修正

    6. LangGraph

    对于更复杂的、有状态的多 Agent 协作场景，推荐使用 LangGraph。它用图（Graph）的方式定义工作流，支持循环、条件分支、多 Agent 协作，比传统 AgentExecutor 更灵活可控。

    💡 何时用 Agent

    用 Agent：任务步骤不固定、需要动态决策、需要调用多个工具
    用 Chain：任务流程固定、可预测

    本章小结

    • Agent = LLM + Tools，自主规划并执行多步任务
    • ReAct 模式：Thought → Action → Observation 循环
    • AgentExecutor 驱动 Agent 执行循环
    • 常见类型：zero-shot-react、react-docstore、self-ask-with-search
    • LangGraph 适合复杂有状态的多 Agent 工作流
