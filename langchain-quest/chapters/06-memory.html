闯关地图

    记忆系统 Memory

    LLM 本身是无状态的——每次调用都是独立的。要让 LLM 应用具备"记忆"，在多轮对话中理解上下文，就需要 Memory 系统。

    学习目标

    • 理解 Memory 的作用和分类
    • 掌握 ConversationBufferMemory、WindowMemory、SummaryMemory
    • 了解 EntityMemory 和 KnowledgeGraphMemory
    • 用 RunnableWithMessageHistory 为 LCEL 链添加记忆

    1. 为什么需要 Memory

    没有记忆时，每次对话都是全新的，LLM 不知道之前聊过什么。Memory 将历史对话注入下一次调用的 prompt，让 LLM 理解指代和省略。

    2. ConversationBufferMemory

    最简单的记忆，存储完整对话历史：

    from langchain.memory import ConversationBufferMemory

memory = ConversationBufferMemory()
memory.save_context({"input": "你好"}, {"output": "你好！有什么可以帮你的？"})
print(memory.load_memory_variables({}))

    优点：简单直接，信息完整。缺点：对话越长，token 消耗越大，可能超出上下文窗口。

    3. ConversationBufferWindowMemory

    只保留最近 K 轮对话，控制 token 消耗：

    from langchain.memory import ConversationBufferWindowMemory

memory = ConversationBufferWindowMemory(k=5)  # 只保留最近 5 轮

    4. ConversationSummaryMemory

    用 LLM 对历史对话生成摘要，用摘要代替原始历史，大幅减少 token：

    from langchain.memory import ConversationSummaryMemory

memory = ConversationSummaryMemory(llm=llm)

    优点：token 消耗低，适合长对话。缺点：可能丢失细节，且摘要本身需要调用 LLM 增加费用。

    5. ConversationEntityMemory

    提取对话中提到的实体（人名、地名、组织等）及其关系，结构化存储：

    from langchain.memory import ConversationEntityMemory

memory = ConversationEntityMemory(llm=llm)

    6. LCEL 中的记忆

    新版推荐用 RunnableWithMessageHistory 包装链：

    from langchain_core.chat_history import InMemoryChatMessageHistory
from langchain_core.runnables.history import RunnableWithMessageHistory

store = {}
def get_session_history(session_id):
    if session_id not in store:
        store[session_id] = InMemoryChatMessageHistory()
    return store[session_id]

chain_with_history = RunnableWithMessageHistory(
    chain,
    get_session_history,
    input_messages_key="question",
    history_messages_key="history",
)
result = chain_with_history.invoke(
    {"question": "我叫小明"},
    config={"configurable": {"session_id": "user_001"}}
)
    💡 记忆策略选择

    短对话 → BufferMemory
    中等对话 → WindowMemory（k=5~10）
    长对话 → SummaryMemory 或 SummaryBufferMemory
    需要实体追踪 → EntityMemory

    本章小结

    • Memory 让 LLM 在多轮对话中保持上下文
    • BufferMemory 存完整历史，WindowMemory 只存最近 K 轮，SummaryMemory 存摘要
    • EntityMemory 提取并存储实体信息
    • LCEL 推荐用 RunnableWithMessageHistory 管理消息历史
