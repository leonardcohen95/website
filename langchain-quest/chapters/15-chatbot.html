    对话系统构建

    对话系统（Chatbot）是 LLM 应用最常见的形态。本章学习如何用 LangChain 构建一个具备多轮对话能力的聊天机器人。

    学习目标

    • 用 ConversationChain 构建基础对话
    • 用 RunnableWithMessageHistory 管理会话历史
    • 处理长对话的上下文溢出
    • 结合 RAG 实现带知识库的对话

    1. 基础对话链

    from langchain.chains import ConversationChain
from langchain.memory import ConversationBufferMemory

conversation = ConversationChain(
    llm=llm,
    memory=ConversationBufferMemory(),
    verbose=True
)
conversation.invoke("你好，我叫小明")
conversation.invoke("我叫什么名字？")  # 会记住"小明"

    2. 用 LCEL 构建对话系统

    from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.chat_history import InMemoryChatMessageHistory
from langchain_core.runnables.history import RunnableWithMessageHistory

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个友好的客服机器人，用中文回答用户问题。"),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{question}")
])
chain = prompt | llm

store = {}
def get_history(session_id):
    if session_id not in store:
        store[session_id] = InMemoryChatMessageHistory()
    return store[session_id]

chain_with_history = RunnableWithMessageHistory(
    chain,
    get_history,
    input_messages_key="question",
    history_messages_key="history",
)

chain_with_history.invoke(
    {"question": "你好"},
    config={"configurable": {"session_id": "user123"}}
)

    3. 处理长对话

    对话历史过长会超出上下文窗口，常用策略：

    • 滑动窗口：只保留最近 K 轮
    • 摘要压缩：用 LLM 将旧对话压缩为摘要
    • 检索历史：将历史对话向量化，检索相关历史而非全部传入

    4. 对话 + RAG

    结合知识库的对话系统，让 AI 既能记住对话，又能基于知识库回答：

    prompt = ChatPromptTemplate.from_messages([
    ("system", "基于以下上下文回答用户问题。如果上下文没有相关信息，就说不知道。\n上下文：{context}"),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{question}")
])

def format_docs(docs):
    return "\n".join(doc.page_content for doc in docs)

chain = (
    {
        "context": itemgetter("question") | retriever | format_docs,
        "question": itemgetter("question"),
        "history": itemgetter("history"),
    }
    | prompt | llm | parser
)

    5. 生产环境的会话存储

    生产环境不要用内存存储历史，应用 Redis、数据库等持久化存储，支持多实例共享：

    • Redis：高性能，适合会话缓存
    • PostgreSQL / MongoDB：持久化存储
    • LangChain 的 RedisChatMessageHistory：开箱即用

    本章小结

    • ConversationChain 快速构建带记忆的对话
    • RunnableWithMessageHistory 为 LCEL 链添加会话管理
    • 长对话用滑动窗口、摘要、检索历史等策略控制长度
    • 对话 + RAG 实现基于知识库的智能客服
    • 生产环境用 Redis 等持久化存储会话
