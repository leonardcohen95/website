考场环境

⚠️ 关键要求
• 私密房间（书房/卧室，不能是公共场所）
• 桌面清空（不能有纸、笔、手机、其他电子设备）

📅 考前全流程

T-14天
报名缴费
通过 Linux Foundation 官网报名，选择考试时间和时区。费用 $395，含 1 次重考机会。
T-7天
跑 PSI 系统检测
访问 syscheck.bridge.psiexams.com，检查摄像头、麦克风、屏幕共享、网络是否达标。
T-1天
环境准备
下载 PSI Secure Browser；重启电脑；关闭杀毒软件/防火墙；清理桌面；准备好身份证原件。
T-30min
登录检查
提前 30 分钟登录 PSI，展示身份证件，环视四周，监考员确认后进入考试环境。
T-0
开始考试
进入 base 节点（普通 user，非 root），每道题开头给 ssh 命令切换集群，按推荐顺序做题。
T+24h
出分
成绩发到报名邮箱，700+ 及格。

🏆 考场必胜技巧

① 每道题的开头都是 ssh 命令
题目格式：ssh cka00000X，必须先切到正确集群，否则零分！所有题目做完要 exit 回 base 节点。
② 开卷考，善用官方文档
允许访问 kubernetes.io/docs、github.com/kubernetes。但搜索结果排序和平时不同，建议用左侧导航栏找。每道题也给了参考链接。
③ 多用 Tab 自动补全
考试环境有自动补全，比手打快 3 倍。例如：
kubectl -n au↑Tab autoscale↑Tab deploy↑Tab apache↑Tab
④ 编辑 YAML 报错要小心
kubectl edit 改错了，第一次 :wq 会报错；第二次 :wq 会回滚所有修改！建议先导出 YAML 改完再 apply。
⑤ Ctrl 快捷键注意区别
操作考试终端说明
复制Ctrl+Shift+C不是 Ctrl+C
粘贴Ctrl+Shift+V不是 Ctrl+V
不杀标签页Ctrl+Alt+WCtrl+W 会关掉 Chrome 标签
⑥ 查字段用 explain
kubectl explain deployment.spec.template.spec.containers.resources —— 不确定 YAML 字段怎么写就查！

📝 推荐做题顺序（2 小时内稳妥通关）

先易后难，先拿分再攻坚。总耗时约 110 分钟，留 10 分钟检查。

第一轮：秒拿分题（≈30 min）

5
Service NodePort
纯 expose 一条命令，3 分钟搞定
1
HPA 自动扩缩容
kubectl autoscale + edit 改窗口
11
CRD 列表 + explain 字段
grep cert-manager + kubectl explain 保存文件
12
ConfigMap immutable
edit ssl_protocols + immutable:true + rollout
4
StorageClass + 默认 SC
WaitForFirstConsumer + 默认注解

第二轮：中等难度（≈40 min）

6
RBAC Role + RoleBinding
导出改资源名，别从零写
2
Ingress
查 ingressclasses 是 edge-proxy（不是旧 nginx）
14
Resources 均分 WordPress
先 scale 0 再算，requests 改小就稳，limits 别动
10
NetworkPolicy 选示例
先看 label，选 netpol2（双重限定）
3
Sidecar 日志容器
导出 YAML → status 上面加 volumes，dnsPolicy 上面加 sidecar

第三轮：root/安装/恢复（≈35 min）

16
cri-dockerd + sysctl
sudo dpkg -i → systemctl enable → sysctl.conf 四条
15
etcd 修复
sudo -i → 改 apiserver manifest → restart kubelet → scheduler requests 改小
13
Calico CNI
两条 kubectl create -f URL，Flannel 不支持 NetworkPolicy 排除

第四轮：收尾攻坚战（≈15 min）

8
MariaDB Retain PV 恢复
kubectl get pv 找 Retain → PVC 绑 volumeName → Deployment 加挂载
7
Helm ArgoCD template
helm repo add argo → helm template --set crds.install=false
9
Gateway API（最难，留最后）
先查旧 Ingress 的 tls/host/path → Gateway → HTTPRoute → delete 旧 Ingress

⌨️ 高频命令速查

# 切集群（每道题开头必须做） kubectl config use-context k8s ssh cka0000XX # 查字段不确定时 kubectl explain deployment.spec.template.spec.containers # 快速生成 YAML（dry-run） kubectl run nginx --image=nginx --dry-run=client -o yaml > pod.yaml # 看事件排错 kubectl get events --sort-by=.metadata.creationTimestamp | tail -20 # 进容器调试 kubectl exec -it -- sh kubectl debug -it --image=busybox # 导出再修改（推荐比 edit 安全） kubectl get deploy xxx -o yaml > xxx.yaml vim xxx.yaml && kubectl apply -f xxx.yaml # Deployment 滚动 kubectl rollout status deploy/xxx --watch kubectl rollout restart deploy/xxx kubectl rollout undo deploy/xxx

⏰ 时间管理红线

🚨 3 条绝对红线，超过必挂
  1. 单题卡超过 8 分钟 → 写 YAML 骨架占坑，exit 跳下一题，回头补
  2. edit 第二次 :wq → 直接 :q! 退出不保存，重来
  3. 剩余时间 < 20 分钟 → 跳过 #9 Gateway，确保其他 15 题至少有骨架
✅ 节省时间的习惯
• ssh 之后再读题（利用延迟时间扫题）
• 做完立刻 exit 回 base 节点
• sudo -i 的题（15、16）放一组做，只切一次 root
• etcd 修复题改完 manifest 必须 restart kubelet
