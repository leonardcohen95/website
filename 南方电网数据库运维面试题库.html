B. Oracle

14 题
9
Oracle 实例和数据库的区别是什么？基础
抓手：实例 = SGA + 后台进程（易失）；数据库 = 数据文件/控制文件/redo/归档（持久）；RAC 多实例共享一库。
10
SGA 由哪些部分组成？PGA 的作用是什么？高频
抓手：Shared Pool / Buffer Cache / Redo Log Buffer / Large Pool / Java Pool；PGA 管排序、Hash、会话私有内存。
11
DBWn、LGWR、CKPT、SMON、PMON、ARCn 分别做什么？
抓手：写数据、写日志、检查点、实例恢复、进程清理、归档；能串成一次事务提交的完整链路最好。
12
Oracle 启动的三个阶段是什么？分别读什么文件？
抓手：nomount（参数文件，建实例）→ mount（控制文件）→ open（数据文件、redo）。
13
逻辑结构和物理结构分别是什么？表空间和 Data File 什么关系？基础
抓手：库→表空间→段→区→块；一个表空间可对应多个数据文件，一个数据文件只属于一个表空间。
14
RAC 的原理是什么？Cache Fusion 怎么工作？高频
抓手：多实例共享存储；GCS/GES 通过私网传块镜像；依赖 OCR、Voting Disk、SCAN/VIP；不防存储单点。
15
RAC 脑裂怎么产生？Voting Disk 起什么作用？深挖
抓手：心跳中断但节点存活 → 双主风险；Voting Disk 仲裁，多数派存活才能组集群，少数派被驱逐。
16
Data Guard 三种保护模式有什么区别？高频
抓手：最大保护（RPO=0，备全挂主库会停）、最高可用（正常 RPO=0，备挂自动降级）、最大性能（异步，RPO>0）。
17
switchover 和 failover 的区别？什么时候用哪个？
抓手：计划内角色互换、不丢数据、可回切 vs 故障强制切换、可能丢数据、原主需重建。
18
RMAN 全备、增量、level 0/1 怎么理解？基础
抓手：level 0 是增量基准；level 1 差异/累积；配合块变更跟踪；归档单独备份。
19
误删了一张表，怎么恢复？高频
抓手：先止损；优先 Flashback Drop/Table；purge 了就用备份 + 归档做表级 PITR；全程保护现场。
20
一条 SQL 突然变慢，你怎么排查？高频
抓手：影响面 → 执行计划 → 统计信息 → 等待事件 → 锁/对象 → OS；处置后对比逻辑读和耗时。
21
AWR 里你最关注哪些指标？ASH 和 AWR 有什么区别？
抓手：DB Time、DB CPU、Top 5 等待、Top SQL；AWR 是快照区间汇总，ASH 是秒级活跃会话采样。
22
遇到过 ORA-01555 / ORA-04031 / 表空间满吗？怎么处理？压力题
抓手：01555 看 undo 保留和长查询；04031 看共享池碎片/绑定变量；表空间满先扩容再查增长根因。讲真实处理顺序。

C. 达梦 DM8

12 题
23
达梦的体系结构由哪几部分组成？高频
抓手：逻辑（库→表空间→段→簇→页）、物理（DBF/ctl/日志/归档/dm.ini）、内存（内存池/ BUFFER/排序/HASH）、线程（监听/工作/IO/日志/归档/定时器）。
24
达梦和 Oracle 最大的区别是什么？高频
抓手：多线程 vs 多进程；端口 5236 vs 1521；Data Watch/DSC/MPP vs DG/RAC；dmrman/dexp vs RMAN/expdp；LSN vs SCN。
25
页大小和簇大小是什么？初始化后能改吗？
抓手：页是最小 IO 单位，常用 8KB；簇默认 16 页；页大小初始化后不可改，迁移前要评估行长度和大字段。
26
达梦的备份方式有哪些？dmrman 和 dexp 有什么区别？基础
抓手：物理（dmrman，全量/增量/归档，整库恢复快）vs 逻辑（dexp/dimp，单表/跨版本灵活）；联机备份需归档模式。
27
Data Watch 的原理是什么？实时主备和异步备怎么选？高频
抓手：日志传输 + 备库重演 + DMWatcher 守护 + Monitor 仲裁；实时备 RPO=0 但影响主库，异步备性能好但 RPO>0。
28
达梦 DSC 和 Oracle RAC 有什么区别？
抓手：都是共享存储多活；DM 用 MAL 网络和自身多线程架构，Oracle 用 GCS/GES + Cache Fusion；都不防存储单点。
29
DM MPP 适合什么场景？和 DSC 怎么选？
抓手：MPP 是 Shared Nothing、按分布键水平拆分，适合分析/海量；DSC 是共享存储多活，适合高并发 OLTP。
30
达梦主备切换怎么做？怎么防脑裂？
抓手：确认延迟和日志追平 → 停业务 → Monitor 切换 → 验证 → 通知；靠 Monitor/仲裁节点和 fencing 防双主。
31
达梦常用动态视图有哪些？
抓手：V$INSTANCE、V$SESSIONS、V$TABLESPACE、V$ARCHIVED_LOG、V$BACKUPSET、V$LOCK、V$TRX、V$SQL。
32
达梦参数调优重点看哪些？
抓手：MEMORY_POOL、BUFFER、SORT_BUF、HASH 区、工作线程数；先定位瓶颈，再单参数调整并压测。
33
Oracle 迁达梦，兼容性最大的坑是什么？高频
抓手：空字符串与 NULL、大小写、ROWNUM/分页、序列、存储过程/包、隐式转换；迁移后执行计划可能变化。
34
达梦生产环境出过什么故障？怎么处理的？压力题
抓手：选真实案例：主备延迟/表空间满/锁等待/连接数满；按“止损→定位→处置→复盘”讲，别编。

D. 金仓 KingbaseES

10 题
35
金仓的底层是什么？为什么能兼容 Oracle？高频
抓手：PostgreSQL 内核；Oracle 兼容模式支持 PL/SQL、ROWNUM、DUAL、序列、同义词、包、DBLink。
36
金仓的进程模型是怎样的？
抓手：postmaster + 每连接一个 backend；辅助进程 checkpointer、bgwriter、walwriter、archiver、autovacuum、stats collector。
37
金仓主备流复制的同步和异步怎么选？高频
抓手：同步 RPO=0 但备库故障影响主库，通常一同步一异步；异步性能好但可能丢数据；看 pg_stat_replication 的 sync_state/replay_lag。
38
同步备库挂了，主库写不进去怎么办？
抓手：先摘除同步备或降级为异步，恢复主库写入；再修备库、重新加入；事后加监控和双备策略。
39
金仓读写分离怎么做？延迟怎么处理？
抓手：RWC 集群/代理路由；强一致读走主库；监控延迟，超阈值摘节点；拆大事务。
40
sys_rman、sys_dump、sys_basebackup 有什么区别？
抓手：sys_rman 物理备份（全量/增量，支持 PITR）；sys_basebackup 基础物理备份；sys_dump 逻辑备份（单库/单表）。
41
什么是 autovacuum？长事务会有什么影响？深挖
抓手：回收死元组、更新统计信息、防事务 ID 回卷；长事务阻止回收导致表膨胀，监控 pg_stat_activity 和表膨胀率。
42
金仓参数调优重点是什么？
抓手：shared_buffers、work_mem、maintenance_work_mem、effective_cache_size、max_connections、checkpoint/autovacuum 相关。
43
金仓表膨胀了怎么处理？
抓手：确认膨胀率 → 手动 VACUUM (FULL) 或 pg_repack 在线整理 → 查长事务/复制槽 → 调 autovacuum 参数。
44
金仓的分布式方案是什么？适合什么场景？
抓手：KES Sharding，水平拆分；适合海量数据、高并发写入；关注分片键、跨片 Join、分布式事务。

E. GaussDB

10 题
45
GaussDB 的 CN、DN、GTM、CM 分别负责什么？高频
抓手：CN 解析优化调度汇总；DN 存分片数据；GTM 全局事务 ID/快照；CM 故障检测与主备切换。
46
分布式表的分布键怎么选？选错了会怎样？
抓手：高基数、均匀、常用 Join/过滤字段；选错会数据倾斜、跨节点重分布、热点 DN。
47
GaussDB 怎么保证高可用？多数派是什么？高频
抓手：DN 一主多备 + 同步复制 + CM 仲裁；多数派 n/2+1 存活才能选主，防止脑裂和数据丢失。
48
GaussDB 的备份工具是什么？怎么做 PITR？
抓手：Roach 并行物理备份（全量/增量）、gs_dump 逻辑、gs_basebackup；归档 + 全量/增量恢复到时间点。
49
EXPLAIN PERFORMANCE 怎么看？重点看什么？
抓手：各 DN 实际耗时、行数估算偏差、Broadcast/Redistribute、数据倾斜、算子落盘。
50
数据倾斜怎么发现、怎么处理？深挖
抓手：看各 DN 数据量/CPU/耗时差异；换分布键、加随机前缀、拆分大客户、调整查询下推。
51
GaussDB 常用运维工具和视图有哪些？
抓手：gs_om、gs_ctl、gs_ssh、gs_check、gs_collector；pg_stat_activity、pg_stat_replication、pg_locks、dbe_perf。
52
GaussDB 扩容怎么做？要注意什么？
抓手：加 DN/加节点 → 数据重分布 → 校验 → 切流量；关注分布键、网络、存储、扩容窗口和回退。
53
GaussDB 和 openGauss 是什么关系？
抓手：openGauss 是开源内核，GaussDB 是华为商业发行版，增强企业级能力、工具和云服务；架构同源。
54
GaussDB 主备切换失败，你怎么排查？压力题
抓手：CM 状态和日志 → 多数派是否满足 → 复制是否中断 → 网络/磁盘 → 禁止强行双主，必要时厂商支持。

F. PolarDB

6 题
55
PolarDB 的计算存储分离架构是什么？有什么优缺点？高频
抓手：计算节点 + 共享存储 PolarFS；扩容/备份/读扩展快；依赖存储和网络，排障要跨层。
56
一写多读是怎么实现的？只读延迟大怎么办？
抓手：共享存储 + 物理复制；延迟看只读节点回放和负载；强一致读走主库，超阈值摘节点。
57
PolarDB 的备份和恢复怎么做？
抓手：存储快照 + 日志备份，支持 PITR；备份快、对业务影响小；跨区域备份防区域故障。
58
PolarDB 扩容为什么快？扩容时要注意什么？
抓手：计算无状态、存储共享；秒级加只读节点/升配；注意连接路由、只读延迟、存储水位。
59
PolarDB-X 和 PolarDB 有什么区别？
抓手：PolarDB 是共享存储云原生；PolarDB-X 是分布式（CN/DN/GMS），水平拆分 + 分布式事务。
60
PolarDB 和传统 RDS 怎么选？
抓手：读扩展、弹性、备份速度选 PolarDB；预算有限、规模小、要求简单选 RDS；核心是业务形态和 SLA。

G. 高可用与容灾

8 题
61
RPO 和 RTO 是什么？你们核心库的指标是多少？高频
抓手：丢多少数据 / 停多久；由业务定；RPO 决定同步异步，RTO 决定自动或手动切换。给出你项目的真实数字。
62
两地三中心怎么设计？深挖
抓手：同城双中心同步 + 自动切换；异地异步/备份；考虑带宽、延迟、切换顺序、回切。
63
高可用切换预案包含哪些内容？
抓手：触发条件、分工、前置检查、步骤、验证点、回退、业务通知、演练复盘。
64
怎么防止脑裂？
抓手：第三方仲裁/多数派/fencing；网络分区宁可停写不做双主；切换前隔离旧主。
65
主备延迟持续增大，怎么排查？高频
抓手：延迟指标 → 主库大事务/写入突增 → 网络 → 备库 IO/CPU/长查询 → 拆事务/限流/扩容/临时异步。
66
读写分离能提升高可用吗？
抓手：不能，只扩展读；主库故障仍需切换方案；读写分离还会带来一致性问题。
67
容灾演练怎么做才有效？
抓手：分级场景、真实切换、业务验证、记录实测 RTO、问题闭环；不是只看脚本跑通。
68
存储双活和数据库主备有什么区别？
抓手：存储双活解决底层存储高可用，数据库感知不到；数据库主备解决逻辑复制和误操作/区域性灾难；两者互补。

H. 备份与恢复

6 题
69
你们的备份策略是什么？高频
抓手：3-2-1；每周全备 + 每天增量 + 归档持续备份；本地快速恢复 + 异地长期保留；定期恢复演练。
70
备份成功就代表能恢复吗？怎么验证？
抓手：不代表；异机恢复演练、备份集校验、归档连续性、实测恢复耗时。
71
误删数据但发现时已经过了两天，怎么恢复？
抓手：确认备份和归档覆盖窗口；恢复到临时库到误删前时点；比对后回写；不要直接覆盖生产。
72
归档日志满了会怎样？怎么处理？
抓手：可能挂起数据库；已备份的按策略清理，未备份的不能删；扩容/加备份频率；加水位告警。
73
没有备份的情况下误删了数据，怎么办？
抓手：保护现场、停止写入；尝试闪回/日志挖掘/回收站；评估厂商支持；最后才是业务重建；强调事前预防。
74
备份窗口和业务高峰冲突，怎么解决？
抓手：增量/归档备份、限速、压缩、备库备份、快照备份、错峰调度；核心是降低对主库 IO 影响。

I. 性能调优与故障处理

10 题
75
数据库整体变慢，你的排查顺序是什么？高频
抓手：业务层 → SQL → 实例（等待事件/锁/内存）→ OS（CPU/IO/内存/网络）→ 存储；先止损再根因。
76
CPU 100% 怎么定位到具体 SQL？高频
抓手：top -Hp 找线程 → 数据库活跃会话/当前 SQL → 执行计划 → 并行度/硬解析/排序溢出。
77
IO 使用率很高，但 CPU 不高，可能是什么原因？
抓手：全表扫描、大排序/Hash 落盘、备份任务、日志写入、存储性能不足；看 iostat await 和数据库等待事件对齐。
78
连接数满了怎么处理？
抓手：查空闲/异常会话、连接泄漏；临时清理/扩容；根因是连接池配置、慢 SQL 占连接、应用未释放。
79
锁等待和死锁怎么处理？高频
抓手：查 blocking session 找根会话；杀代价小的事务；根治靠缩短事务、统一加锁顺序、超时重试。
80
执行计划突然变了，怎么办？
抓手：对比前后计划、统计信息、绑定变量、数据分布、参数；用 SQL Plan Baseline/Profile 固定，再根治。
81
全表扫描一定比索引扫描差吗？
抓手：不一定；小表、高比例返回、宽表顺序读可能更优；看逻辑读、返回行数占比、实际耗时。
82
索引失效的常见场景有哪些？
抓手：函数/运算、隐式转换、前导模糊、最左前缀、or、not in/!=、数据倾斜、统计信息过期。
83
你们做过哪些 OS 层调优？
