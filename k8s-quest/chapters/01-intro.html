    什么是 Kubernetes

    在动手之前，我们先搞清楚：Kubernetes 到底是什么？它解决了什么问题？为什么所有云原生公司都在用它？

    学习目标

    • 理解容器编排的概念
    • 知道 Kubernetes 能解决什么问题
    • 了解 K8s 的核心价值

    1. 从容器到容器编排

    你应该已经听过 Docker 了。Docker 让我们可以把应用打包成容器， 一次打包，到处运行。但问题来了：当你的应用从 1 个容器 变成 100 个、1000 个容器 时，谁来管理它们？

    举个例子

    你有一个电商网站，用了 50 个微服务，每个服务跑 3 个容器，总共 150 个容器。 突然某个容器挂了，谁来重启它？流量大了，谁来自动扩容？ 要发布新版本，谁来帮你滚动更新而不影响用户？

    这就是 容器编排（Container Orchestration） 要解决的问题。

    2. Kubernetes 是什么

    Kubernetes（简称 K8s，因为 K 和 s 之间有 8 个字母）是 Google 开源的 容器编排平台。它的作用是：自动化部署、扩展和管理容器化应用。

    大白话理解

    如果把容器比作"集装箱"，那 K8s 就是"港口调度系统"。 它帮你决定：哪个集装箱放哪艘船、船怎么编队、出问题了怎么换、货多了怎么加船。

    3. K8s 能做什么

    🤖 自动调度

    自动决定容器在哪个节点上运行，根据资源情况智能分配。

    ❤️ 自我修复

    容器挂了自动重启，节点挂了自动迁移容器到其他节点。

    📈 自动扩缩容

    根据 CPU/内存或自定义指标，自动增加或减少容器数量。

    🔄 滚动更新

    发布新版本时逐个替换容器，不中断服务，出问题可一键回滚。

    🌐 服务发现

    容器之间可以通过名字互相访问，不用关心 IP 变化。

    💾 存储编排

    自动挂载存储卷，支持本地存储、云存储等多种后端。

    4. 为什么选 K8s

    市面上也有其他容器编排工具（如 Docker Swarm、Apache Mesos），但 K8s 已经成为事实标准，原因是：

    • 功能强大：覆盖部署、网络、存储、安全全链路
    • 生态丰富：Helm、Prometheus、Istio 等工具无缝集成
    • 云厂商支持：AWS EKS、Azure AKS、Google GKE 都是托管 K8s
    • 社区活跃：Google、Red Hat、Microsoft 等大厂共同维护
    注意

    K8s 功能强大，但学习曲线也陡。本教程会循序渐进，从概念到实操，帮你一步步征服它。

    本章小结

    • K8s 是容器编排平台，自动化管理大规模容器
    • 核心能力：调度、自愈、扩缩容、滚动更新、服务发现
    • K8s 是云原生时代的事实标准
