    第 3 章 核心能力 约 20 分钟

    第一个 Agent：调用大模型

    这一章我们正式写代码！你将学会如何用 Python 调用大语言模型（LLM）的 API， 让程序生成文字回答。这是构建 Agent 的第一步——先让「大脑」转起来。

    学习目标

    • 理解 prompt（提示词）的概念
    • 学会调用通义千问 / OpenAI 的 API
    • 理解 system、user、assistant 三种消息角色
    • 写出第一个能回答问题的 Python 程序

    1. 关键概念

    LLM（大语言模型）

    Large Language Model，能理解和生成人类语言的 AI 模型，比如 GPT、通义千问、文心一言等。

    Prompt（提示词）

    你发给模型的文字指令。模型根据 prompt 生成回答。prompt 的质量直接决定回答质量。

    Token

    模型处理文字的最小单位。大约 1 个汉字 ≈ 1-2 个 token，1 个英文单词 ≈ 1 个 token。 模型有「上下文窗口」限制，比如 8K token，意味着输入+输出加起来不能超过约 8000 个 token。

    消息角色（Role）

    对话中的每条消息都有角色：
    - system：系统提示，设定模型的行为和身份
    - user：用户说的话
    - assistant：模型的回复

    2. 调用通义千问 API

    创建 agent.py，写入以下代码：

    import os                          # 导入 os 模块，用于读取环境变量
from dotenv import load_dotenv     # 导入 load_dotenv，用于读取 .env 文件
import dashscope                   # 导入阿里云的通义千问 SDK

load_dotenv()                      # 加载 .env 文件中的环境变量
dashscope.api_key = os.getenv("DASHSCOPE_API_KEY")  # 从环境变量读取 API Key，设置给 dashscope


def ask_llm(prompt: str) -> str:
    """调用通义千问，返回模型回答"""
    # dashscope.Generation.call 是调用模型的方法
    response = dashscope.Generation.call(
        model="qwen-turbo",                                       # 指定使用的模型名称
        messages=[{"role": "user", "content": prompt}],           # messages 是消息列表，这里只有一条用户消息
        result_format="message",                                  # 返回结果的格式，message 格式便于解析
    )
    # response.output.choices[0].message.content 取出模型生成的回答文本
    return response.output.choices[0].message.content


if __name__ == "__main__":  # 当直接运行这个文件时执行下面的代码（被导入时不执行）
    answer = ask_llm("用一句话解释什么是人工智能")  # 调用函数，传入问题
    print("回答:", answer)  # 打印结果

    运行：

    python agent.py

    如果一切正常，你会看到模型生成的一句话解释。恭喜，你已经调用了 LLM！

    3. 调用 OpenAI API（备选）

    如果你用的是 OpenAI，代码如下：

    import os                          # 导入 os 模块
from dotenv import load_dotenv     # 导入读取 .env 的函数
from openai import OpenAI          # 从 openai 库导入 OpenAI 客户端类

load_dotenv()                      # 加载 .env 文件
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))  # 创建 OpenAI 客户端，传入 API Key


def ask_llm(prompt: str) -> str:
    # 调用 chat.completions.create 创建一次对话请求
    response = client.chat.completions.create(
        model="gpt-4o-mini",                              # 指定模型
        messages=[{"role": "user", "content": prompt}],   # 消息列表
    )
    return response.choices[0].message.content            # 取出回答文本


if __name__ == "__main__":
    print("回答:", ask_llm("用一句话解释什么是人工智能"))  # 调用并打印
    两种 API 的区别

    通义千问用 dashscope 库，OpenAI 用 openai 库。 它们的调用方式非常相似，核心都是「发送 messages 列表，拿到 content」。 后续章节的代码以通义千问为例，用 OpenAI 的同学只需替换 ask_llm 函数内部即可。

    4. 加入 system 提示

    目前我们只发了一条 user 消息。如果想让模型扮演某种角色， 可以加一条 system 消息： 

    # system_prompt 有默认值 "你是一个乐于助人的助手。"，调用时可以不传
def ask_llm(prompt: str, system_prompt: str = "你是一个乐于助人的助手。") -> str:
    response = dashscope.Generation.call(
        model="qwen-turbo",
        messages=[
            {"role": "system", "content": system_prompt},  # system 消息：设定模型身份
            {"role": "user", "content": prompt},            # user 消息：用户的问题
        ],
        result_format="message",
    )
    return response.output.choices[0].message.content


if __name__ == "__main__":
    # 调用 ask_llm，第一个位置参数是 prompt，第二个用关键字参数传 system_prompt
    ans = ask_llm(
        "我该怎么学习编程？",
        system_prompt="你是一位经验丰富的编程导师，回答要简洁实用。",
    )
    print(ans)

    5. 理解整个调用过程

    你的代码
   │  发送 POST 请求（含 API Key 和 messages）
   ▼
大模型服务器
   │  处理 prompt，生成回答
   ▼
返回 JSON 响应（含生成的文字）
   │
   ▼
你的代码解析出 content 并打印
    常见错误
    • API Key 无效：检查 .env 文件和变量名是否正确
    • 余额不足：去控制台充值或换用免费额度的模型
    • 模型不存在：确认模型名称拼写正确（如 qwen-turbo）
    • 网络超时：国内用户用通义千问更稳定

    本章小结

    • LLM 通过 API 调用，核心是发送 messages 列表
    • 消息有三种角色：system、user、assistant
    • Prompt 质量决定回答质量，system 消息可以设定模型人设
    • 现在的 ask_llm 函数就是 Agent 的「大脑」，后面我们会给它加记忆和工具
