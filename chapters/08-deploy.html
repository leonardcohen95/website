    1. 把 Agent 做成 Web 接口

    我们用 Flask 把 Agent 封装成一个 HTTP 接口，这样前端网页就能调用它。

    先安装 Flask：

    pip install flask flask-cors

    创建 app.py：

    import os                              # os 模块
from dotenv import load_dotenv         # 读取 .env
import dashscope                       # 通义千问 SDK
from flask import Flask, request, jsonify  # 导入 Flask 框架的组件
from flask_cors import CORS            # 导入跨域支持

load_dotenv()                          # 加载 .env
dashscope.api_key = os.getenv("DASHSCOPE_API_KEY")  # 设置 API Key

app = Flask(__name__)  # 创建 Flask 应用实例，__name__ 是当前模块名
CORS(app)              # 允许跨域请求（前端网页可以调用这个接口）


# @app.route 是装饰器，把下面的函数绑定到指定的 URL 路径
# methods=["POST"] 表示只接受 POST 请求
@app.route("/chat", methods=["POST"])
def chat():  # 处理 /chat 请求的函数
    data = request.get_json()  # 从请求中取出 JSON 数据
    user_input = data.get("message", "")  # 取出 message 字段，没有就用空字符串
    if not user_input:  # 如果用户没输入内容
        return jsonify({"error": "请输入消息"}), 400  # 返回错误，400 是 HTTP 状态码表示请求有误

    # 调用通义千问
    response = dashscope.Generation.call(
        model="qwen-turbo",
        messages=[{"role": "user", "content": user_input}],
        result_format="message",
    )
    answer = response.output.choices[0].message.content  # 取出回答
    return jsonify({"reply": answer})  # 把回答以 JSON 格式返回


@app.route("/")  # 绑定根路径 /
def index():
    return "AI Agent 运行中！"  # 访问根路径时返回这句话


if __name__ == "__main__":
    # host="0.0.0.0" 表示监听所有网络接口（允许外部访问）
    # port=5000 表示使用 5000 端口
    app.run(host="0.0.0.0", port=5000)

    本地测试：

    python app.py
# 另开一个终端测试
curl -X POST http://localhost:5000/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"你好"}'

    2. 免费部署到公网

    有几个完全免费的平台可以部署 Python 后端：

    方案 A：Render（推荐，最简单）

    1. 注册 render.com（免费）
    2. 把代码推到 GitHub 仓库
    3. 在 Render 上点「New → Web Service」，连接你的 GitHub 仓库
    4. 配置：
      • Build Command: pip install -r requirements.txt
      • Start Command: gunicorn app:app
      • 环境变量：添加 DASHSCOPE_API_KEY
    5. 点击部署，几分钟后得到一个 https://xxx.onrender.com 的公网地址

    需要创建 requirements.txt：

    flask
flask-cors
dashscope
python-dotenv
gunicorn

    方案 B：Hugging Face Spaces

    1. 注册 huggingface.co
    2. 创建一个 Space，SDK 选 Docker 或 Gradio
    3. 上传代码，设置环境变量中的 API Key
    4. 得到 https://xxx.hf.space 的公网地址

    方案 C：Railway / Fly.io

    同样提供免费额度，支持 Docker 部署，操作类似 Render。

    3. 免费域名

    上面的平台会给你一个免费的二级域名（如 xxx.onrender.com），已经可以公网访问。 如果你想要更个性化的域名，有以下免费选择：

    • is-a.dev：免费子域名，如 yourname.is-a.dev
    • js.org：面向 JS 项目的免费子域名
    • GitHub Pages：yourname.github.io（适合纯静态网站）
    • Cloudflare Pages：免费托管 + 可绑定自定义域名
    本教程网站的部署

    这个教程网站本身是纯静态 HTML，可以直接用 GitHub Pages 免费部署，还能获得 你的用户名.github.io/仓库名 的免费域名。 部署方法见本仓库的 README。

    4. 做一个简单的聊天界面

    创建 index.html 作为前端，调用我们的接口：

    <!DOCTYPE html>
<html>
<body>
  <h1>我的 AI Agent</h1>
  <div id="chat"></div>                          <!-- 聊天记录显示区域 -->
  <input id="msg" placeholder="输入消息..." />     <!-- 输入框 -->
  <button onclick="send()">发送</button>          <!-- 点击触发 send 函数 -->
  <script>
    const API = "https://你的地址.onrender.com/chat";  // 后端接口地址
    async function send() {                            // async 表示这是异步函数
      const text = document.getElementById("msg").value;  // 获取输入框的文字
      const resp = await fetch(API, {                   // fetch 发送 HTTP 请求，await 等待结果
        method: "POST",                                 // POST 请求
        headers: {"Content-Type": "application/json"},  // 告诉服务器发送的是 JSON
        body: JSON.stringify({message: text})           // 把消息转成 JSON 字符串
      });
      const data = await resp.json();                   // 把响应解析成 JSON 对象
      document.getElementById("chat").innerHTML +=      // 把对话追加到页面
        "<p><b>你：</b>" + text + "</p>" +
        "<p><b>Agent：</b>" + data.reply + "</p>";
    }
  </script>
</body>
</html>
