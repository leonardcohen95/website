    第 2 章 环境准备 约 15 分钟

    环境准备

    工欲善其事，必先利其器。本章我们把开发环境搭好：安装 Python、获取 API Key、安装依赖库。

    学习目标

    • 确认电脑上安装了 Python 3.8+
    • 学会使用 pip 安装第三方库
    • 获取一个大模型 API Key（以通义千问/OpenAI 为例）
    • 配置好环境变量，安全存放 API Key

    1. 安装 Python

    打开终端（Windows 用 PowerShell 或 CMD，macOS/Linux 用 Terminal），输入以下命令检查版本： 

    python --version
# 或者
python3 --version

    如果显示 Python 3.8.x 或更高版本，就可以继续。如果没有安装， 去 Python 官网 下载最新版安装即可（安装时记得勾选「Add Python to PATH」）。

    建议版本

    推荐使用 Python 3.10 或 3.11，兼容性最好。Python 2 已经停止维护，不要用。

    2. 创建项目目录

    为了有条理，我们新建一个专门的文件夹存放本教程的代码：

    mkdir ai-agent-tutorial
cd ai-agent-tutorial

    3. 安装依赖库

    本教程主要用到以下库：

    • requests：发 HTTP 请求调用 API
    • python-dotenv：从 .env 文件读取环境变量
    • dashscope：阿里云通义千问 SDK（如果用通义）
    • openai：OpenAI 官方 SDK（如果用 GPT）

    安装命令：

    pip install requests python-dotenv

    如果你用通义千问，再装 pip install dashscope； 如果用 OpenAI，再装 pip install openai。

    4. 获取 API Key

    Agent 的大脑是大语言模型（LLM）。我们需要通过 API 调用它，所以要先获取一个 API Key（相当于调用接口的「钥匙」）。

    术语解释

    API Key 是一串密钥，服务商通过它识别「是谁在调用」并计费。 千万不要把它写死在代码里，更不要上传到公开仓库，否则别人可能盗用你的额度。

    方案 A：通义千问（推荐国内用户）

    1. 访问 阿里云百炼控制台
    2. 注册并登录账号
    3. 在「API-KEY 管理」页面创建一个 API Key
    4. 复制保存好（只显示一次）

    方案 B：OpenAI（国际用户）

    1. 访问 OpenAI Platform
    2. 注册并登录
    3. 点击「Create new secret key」生成 API Key
    4. 复制保存好

    5. 安全存放 API Key

    我们用 .env 文件来存放密钥，然后让程序读取它。

    在项目目录下创建 .env 文件：

    DASHSCOPE_API_KEY=你的通义千问Key
# 或者
OPENAI_API_KEY=你的OpenAIKey

    然后创建一个 .gitignore 文件，防止密钥被提交到 Git：

    .env
__pycache__/
*.pyc

    测试一下能否读取到密钥。创建 test_env.py：

    import os                        # 导入 Python 内置的 os 模块，用来和操作系统交互（比如读环境变量）
from dotenv import load_dotenv   # 从 python-dotenv 库导入 load_dotenv 函数，它能读取 .env 文件

load_dotenv()                    # 调用 load_dotenv()，把 .env 文件里的键值对加载到环境变量中

api_key = os.getenv("DASHSCOPE_API_KEY")  # os.getenv() 从环境变量中读取名为 DASHSCOPE_API_KEY 的值，赋给变量 api_key
print("API Key 前 8 位:", api_key[:8] if api_key else "未找到")
# print() 是打印函数，把内容输出到屏幕
# api_key[:8] 表示取字符串的前 8 个字符（切片，从第 0 位到第 7 位）
# if api_key else "未找到" 是三元表达式：如果 api_key 不为空就显示前 8 位，否则显示"未找到"

    运行：

    python test_env.py

    如果看到 API Key 的前 8 位，说明环境配置成功。

    为什么用 .env？

    把密钥放在环境变量里，代码本身就不含密钥。这样代码可以放心分享、上传到 GitHub， 而密钥只存在于你自己电脑的 .env 文件中。

    本章小结

    • 安装 Python 3.8+ 和 pip
    • 安装 requests、python-dotenv 等依赖
    • 获取大模型 API Key（通义千问或 OpenAI）
    • 用 .env 文件安全存放密钥，并用 .gitignore 排除它
