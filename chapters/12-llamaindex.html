    LlamaIndex 实战：专业 RAG 框架

    第 9、10 章我们手写了完整的 RAG 流程，代码不少。 LlamaIndex 是一个专门为 RAG 设计的框架， 把「文档加载 → 分块 → 向量化 → 建索引 → 检索 → 生成」全流程封装好， 几行代码就能跑通一个生产级 RAG 系统。

    学习目标

    • 理解 LlamaIndex 的定位和核心概念
    • 掌握 Document、Node、Index、QueryEngine 四大核心对象
    • 用 LlamaIndex 快速搭建一个 RAG 问答系统
    • 学会自定义分块策略和检索参数
    • 了解 LlamaIndex 与 LangChain 的区别与配合

    1. LlamaIndex 是什么

    LlamaIndex（旧名 GPT Index）是一个以「数据」为中心的 LLM 框架， 它专注于把你的私有数据（文档、数据库、API）接入大模型。 如果说 LangChain 是「什么都能做的瑞士军刀」，那 LlamaIndex 就是 「专门做 RAG 的手术刀」——在 RAG 这件事上更专业、更简单。

    和 LangChain 的区别
    • LangChain：通用框架，擅长 Agent、工具调用、工作流编排
    • LlamaIndex：专注 RAG，文档处理和检索能力更强、配置更少
    • 两者可以配合使用：用 LlamaIndex 做 RAG 检索，再把检索结果交给 LangChain 的 Agent 处理

    安装：

    pip install llama-index llama-index-llms-openai llama-index-embeddings-openai

    2. LlamaIndex 的核心概念

    Document（文档）

    一整份原始资料，比如一个 PDF 文件、一段文字。LlamaIndex 会自动加载并解析。

    Node（节点）

    Document 被切分后的小块，相当于第 9 章的 Chunk。每个 Node 有自己的向量和元数据。

    Index（索引）

    把所有 Node 组织成可检索的数据结构。最常用的是 VectorStoreIndex（向量索引）。

    QueryEngine（查询引擎）

    对 Index 提问的接口。它内部自动完成「检索相关 Node → 拼 Prompt → 调用模型生成答案」。

    3. 用 LlamaIndex 搭建最简 RAG

    先配置通义千问（兼容 OpenAI 接口），然后加载文档、建索引、提问。 创建 llama_demo.py： 

    import os
from dotenv import load_dotenv
from llama_index.core import SimpleDirectoryReader, VectorStoreIndex, Settings
from llama_index.llms.openai import OpenAI
from llama_index.embeddings.openai import OpenAIEmbedding

load_dotenv()

# 配置 LLM：用 OpenAI 兼容模式连通义千问
Settings.llm = OpenAI(
    model="qwen-turbo",
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
)
# 配置 Embedding 模型
Settings.embed_model = OpenAIEmbedding(
    model="text-embedding-v3",
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
)

# SimpleDirectoryReader 读取指定目录下的所有文档（支持 .txt/.md/.pdf/.docx 等）
documents = SimpleDirectoryReader("./data").load_data()

# VectorStoreIndex 自动完成：分块 → 向量化 → 建索引
index = VectorStoreIndex.from_documents(documents)

# as_query_engine() 把索引变成可提问的查询引擎
query_engine = index.as_query_engine()

# 提问！LlamaIndex 自动检索 + 生成
response = query_engine.query("这款产品的保修期是多久？")
print(response)
    只需 3 步

    对比第 9 章手写的几十个函数，LlamaIndex 只要三步： load_data() 加载 → from_documents() 建索引 → query() 提问。文档解析、分块、向量化、检索、生成全自动。

    4. 自定义分块策略

    默认分块不一定适合你的文档。LlamaIndex 可以自定义 SentenceSplitter， 控制块大小和重叠。 

    from llama_index.core.node_parser import SentenceSplitter

# 自定义分块器：每块 500 字符，重叠 100 字符
splitter = SentenceSplitter(chunk_size=500, chunk_overlap=100)

# 建索引时指定分块器
index = VectorStoreIndex.from_documents(
    documents,
    transformations=[splitter],  # transformations 列表：指定文档处理流水线
)
    按句子分块的好处

    SentenceSplitter 会优先在句子边界切分，而不是硬切字符数。 这样每个块的语义更完整，检索和生成效果更好。

    5. 调整检索参数

    通过 as_query_engine 的参数，可以控制检索多少个块、用什么方式检索。 

    # similarity_top_k 控制返回最相关的几个块（默认 2）
query_engine = index.as_query_engine(
    similarity_top_k=5,             # 检索前 5 个最相关的块
    response_mode="compact",        # 生成模式：compact 会先压缩再生成
)

response = query_engine.query("产品有哪些功能？")
print(response)

# 可以查看检索到了哪些源文档
for node in response.source_nodes:
    print("相关片段：", node.text[:100])   # 打印每个源块的前 100 字
    print("相似度：", node.score)           # 相似度分数
    print("---")

    6. 切换检索模式

    LlamaIndex 支持多种检索模式，除了默认的向量检索，还有关键词检索、混合检索等。 

    from llama_index.core.retrievers import VectorIndexRetriever
from llama_index.core.query_engine import RetrieverQueryEngine

# 手动创建检索器，可以更精细地控制
retriever = VectorIndexRetriever(
    index=index,
    similarity_top_k=5,
)

# 用自定义检索器创建查询引擎
query_engine = RetrieverQueryEngine.from_args(retriever)
response = query_engine.query("如何申请售后？")
print(response)
    进阶方向

    LlamaIndex 还支持：多路召回（QueryFusionRetriever）、 重排序（接入 reranker 模型）、路由查询 （不同问题走不同索引）等。这些对应第 10 章讲的优化手段， 在 LlamaIndex 里都有现成组件，无需手写。

    7. 保存和加载索引

    每次重新建索引要重新向量化，又慢又费钱。可以把索引存到磁盘，下次直接加载。 

    # 保存索引到磁盘（默认存到 ./storage 目录）
index.storage_context.persist(persist_dir="./storage")

# 下次启动时从磁盘加载，不用重新向量化
from llama_index.core import StorageContext, load_index_from_storage

storage_context = StorageContext.from_defaults(persist_dir="./storage")
index = load_index_from_storage(storage_context)

    本章小结

    • LlamaIndex 是专注 RAG 的框架，文档处理和检索能力更强
    • 核心对象：Document → Node → Index → QueryEngine
    • 最简流程：load_data → from_documents → query，三步搞定 RAG
    • 可自定义分块策略（chunk_size、chunk_overlap）和检索参数（top_k）
    • 索引可以持久化到磁盘，避免重复向量化
