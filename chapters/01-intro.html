    认识 AI Agent

    在动手写代码之前，我们先搞清楚：到底什么是 AI Agent？它和你平时用的聊天机器人有什么不同？

    学习目标

    • 理解什么是 AI Agent
    • 区分 Agent 与普通聊天机器人
    • 了解 Agent 的核心组成部分

    1. 什么是 AI Agent

    AI Agent（智能体）可以理解为一个「能自主决策并执行任务的 AI 程序」。 它不只是被动地回答问题，而是能根据目标，主动思考、调用工具、执行操作， 最终帮你把事情办成。

    大白话理解

    普通聊天机器人就像一个「只能说话的顾问」——你问它天气，它只能告诉你「我无法获取实时天气」。 而 Agent 像一个「会干活的助理」——你问它天气，它会自己打开天气工具查一下，然后把结果告诉你。

    2. Agent 的核心能力

    一个完整的 AI Agent 通常具备以下几种能力：

    感知（Perception）

    理解用户输入的文字、图片等信息，知道你想让它做什么。

    规划（Planning）

    把一个大任务拆解成若干小步骤，决定先做什么、后做什么。

    工具调用（Tool Use）

    调用外部功能，比如查天气、搜网页、读文件、发邮件等。

    记忆（Memory）

    记住之前的对话和已完成的步骤，保持上下文连贯。

    反思（Reflection）

    检查自己的回答是否正确，发现错误就修正。

    3. Agent vs 聊天机器人

    用一张表来对比：

    对比维度      聊天机器人        AI Agent
-------------------------------------------
主动性        被动回答          主动执行任务
工具          不能用            能调用外部工具
记忆          通常无（或有限）  有上下文记忆
目标          回答一个问题      完成一件事情
例子          问它1+1=几        帮我订明天去北京的机票

    4. Agent 的工作流程

    一个典型的 Agent 执行过程像一个循环：

    用户输入 → 理解意图 → 思考要做什么 → 选择工具 → 执行
   ↑                                          ↓
   └──────── 返回结果给用户 ← 观察执行结果 ←──┘

    这个循环会一直进行，直到任务完成。你会在后续章节看到，这个「思考-行动-观察」的循环 就是著名的 ReAct 模式，我们会在第 6 章详细实现它。

    学习建议

    如果你之前只接触过「调用 LLM 接口返回一个回答」，那么请记住： Agent = LLM + 记忆 + 工具 + 规划。 本教程的后续章节，就是逐一给 LLM 加上这三样东西。

    本章小结

    • AI Agent 是能自主决策、调用工具、完成任务的 AI 程序。
    • 它比普通聊天机器人多了工具调用、规划和记忆能力。
    • 核心公式：Agent = LLM + 记忆 + 工具 + 规划。
