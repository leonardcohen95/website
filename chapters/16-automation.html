    Shell 与 Python 自动化运维

    岗位要求熟悉 Shell、Python 并具备自动化运维经验。本章先讲 Shell 脚本的核心语法和 高频场景，再用 Python 写运维脚本，最后介绍 Ansible 做批量自动化。 学完你能写出可维护的脚本，把重复劳动交给机器。

    学习目标

    • 掌握 Shell 脚本的变量、条件、循环、函数
    • 能编写日志清理、健康检查、批量部署等实用脚本
    • 掌握 Python 运维常用库（subprocess、psutil、paramiko）
    • 理解 Ansible 的 Playbook 写法，实现批量运维

    1. Shell 脚本核心语法

    运维场景里 Shell 脚本无处不在。先把几个核心语法吃透，写脚本就不慌了。

    1.1 变量与引号

    #!/bin/bash
# 变量赋值，等号两边不能有空格
name="prod-server"
port=8080

# 引用变量用 $name 或 ${name}
echo "服务器名: ${name}, 端口: ${port}"

# 单引号不解析变量，双引号解析
echo '单引号: ${name}'      # 输出 单引号: ${name}
echo "双引号: ${name}"      # 输出 双引号: prod-server

# 命令替换：把命令输出赋给变量
ip=$(hostname -I | awk '{print $1}')
echo "本机IP: ${ip}"

# 默认值：变量未设置时用默认值
echo "未定义的变量: ${undefined:-default_value}"

    1.2 条件判断

    # 字符串判断
if [ "$name" = "prod-server" ]; then
    echo "是生产环境"
fi

# 数字判断（注意 -eq 不是 ==）
if [ $port -ge 80 ] && [ $port -le 65535 ]; then
    echo "端口合法"
fi

# 文件判断
if [ -f /etc/passwd ]; then   # -f 文件存在
    echo "文件存在"
fi
if [ -d /var/log ]; then      # -d 目录存在
    echo "目录存在"
fi
if [ -x /usr/bin/python3 ]; then  # -x 可执行
    echo "可执行"
fi

# 命令返回值判断
if ping -c 1 192.168.1.1 &>/dev/null; then
    echo "网络通"
else
    echo "网络不通"
fi
    判断的坑

    [ ] 是 test 命令，内部两边必须有空格！ 字符串比较用 = 或 ==，数字比较用 -eq -ne -gt -lt -ge -le。 更推荐用 [[ ]]（Bash 扩展语法，支持正则和逻辑运算更灵活）。

    1.3 循环与函数

    # for 循环：遍历文件
for file in /var/log/*.log; do
    echo "处理: $file"
done

# while 循环：逐行读文件
while read line; do
    echo "$line"
done < /etc/hosts

# 函数
check_port() {
    local port=$1    # local 定义局部变量
    if ss -tnlp | grep -q ":${port} "; then
        return 0     # 返回 0 表示成功
    else
        return 1
    fi
}

if check_port 8080; then
    echo "8080 端口在监听"
fi

    2. 高频 Shell 脚本实战

    2.1 日志清理脚本（带保留天数和白名单）

    #!/bin/bash
# 清理 7 天前的日志，排除 .gz 压缩包和 current 目录

LOG_DIR=/var/log/app
DAYS=7

find "$LOG_DIR" -type f -name "*.log" -mtime +$DAYS \
    ! -name "*.gz" ! -path "*/current/*" \
    -delete

echo "已清理 $LOG_DIR 下 $DAYS 天前的日志"

    2.2 服务健康检查并告警

    #!/bin/bash
URL="http://localhost:8080/health"
ALERT_WEBHOOK="https://hooks.example.com/alert"

# 连续检查 3 次，避免误报
fail_count=0
for i in 1 2 3; do
    if curl -sf "$URL" > /dev/null; then
        echo "健康检查通过"
        exit 0
    fi
    fail_count=$((fail_count + 1))
    sleep 5
done

# 三次都失败，发告警
curl -X POST "$ALERT_WEBHOOK" \
    -H "Content-Type: application/json" \
    -d "{\"msg\": \"服务 $URL 健康检查连续 ${fail_count} 次失败\"}"

exit 1

    2.3 批量操作多台机器

    #!/bin/bash
# servers.txt 每行一个 IP
SERVERS=servers.txt
CMD="df -h / | tail -1"

while read ip; do
    echo "=== $ip ==="
    # sshpass 非交互式登录（生产建议用密钥）
    sshpass -p '密码' ssh -o StrictHostKeyChecking=no root@$ip "$CMD"
done < "$SERVERS"
    生产环境不要用密码

    脚本里写密码是大忌。生产环境务必配置 SSH 密钥免密登录， 并通过 ssh-copy-id 分发公钥。密码硬编码的脚本如果泄露到 Git，就是安全事故。

    3. Python 运维脚本

    Shell 适合简单的命令编排，遇到复杂逻辑（解析 JSON、调用 API、操作数据库）就力不从心了。 这时用 Python 更合适。

    3.1 用 subprocess 调用系统命令

    import subprocess

# 执行命令并获取输出
result = subprocess.run(
    ["df", "-h", "/"],
    capture_output=True,
    text=True
)
if result.returncode == 0:
    print(result.stdout)
else:
    print("错误:", result.stderr)

# 带超时和输入的调用
try:
    out = subprocess.run(
        ["grep", "error", "/var/log/app.log"],
        capture_output=True, text=True, timeout=10
    ).stdout
    print(f"找到 {len(out.splitlines())} 条错误日志")
except subprocess.TimeoutExpired:
    print("命令超时")

    3.2 用 psutil 监控系统资源

    import psutil
import json

def collect_metrics():
    metrics = {
        "cpu_percent": psutil.cpu_percent(interval=1),
        "memory": {
            "total": psutil.virtual_memory().total,
            "used": psutil.virtual_memory().used,
            "percent": psutil.virtual_memory().percent,
        },
        "disk": {
            "total": psutil.disk_usage("/").total,
            "used": psutil.disk_usage("/").used,
            "percent": psutil.disk_usage("/").percent,
        },
        "net_io": {
            "bytes_sent": psutil.net_io_counters().bytes_sent,
            "bytes_recv": psutil.net_io_counters().bytes_recv,
        },
    }
    return metrics

if __name__ == "__main__":
    m = collect_metrics()
    print(json.dumps(m, indent=2, ensure_ascii=False))

    # 简单告警
    if m["memory"]["percent"] > 85:
        print(f"⚠️ 内存使用率 {m['memory']['percent']}%，超过 85%")
    if m["disk"]["percent"] > 90:
        print(f"⚠️ 根分区使用率 {m['disk']['percent']}%，超过 90%")
    psutil 是运维利器

    psutil 相当于把 top、df、free、netstat 等命令封装成了 Python API， 跨平台且返回结构化数据，非常适合写监控脚本。安装：pip install psutil。

    3.3 用 paramiko 远程执行命令

    import paramiko

def run_remote(host, user, key_file, command):
    client = paramiko.SSHClient()
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    client.connect(host, username=user, key_filename=key_file, timeout=10)

    stdin, stdout, stderr = client.exec_command(command)
    out = stdout.read().decode()
    err = stderr.read().decode()
    code = stdout.channel.recv_exit_status()

    client.close()
    return code, out, err

# 批量检查多台机器磁盘
hosts = ["192.168.1.10", "192.168.1.11", "192.168.1.12"]
for host in hosts:
    code, out, err = run_remote(host, "root", "~/.ssh/id_rsa", "df -h / | tail -1")
    status = "✅" if code == 0 else "❌"
    print(f"{status} {host}: {out.strip()}")

    4. Ansible 批量自动化

    当机器数量变多，手写 SSH 循环脚本不够用了。Ansible 是运维自动化的标配， 它基于 SSH，无需在客户端装 Agent，用 YAML 描述任务，幂等可重复执行。

    4.1 安装与 Inventory

    # 安装
pip install ansible

# 编写 inventory（主机清单），保存为 hosts.ini
# [webservers]
# 192.168.1.10 ansible_user=root
# 192.168.1.11 ansible_user=root
#
# [dbservers]
# 192.168.1.20 ansible_user=root

    4.2 Ad-Hoc 命令（一次性操作）

    # 检查所有 web 服务器的连通性
ansible webservers -i hosts.ini -m ping

# 批量安装 nginx
ansible webservers -i hosts.ini -m yum -a "name=nginx state=present"

# 批量启动服务
ansible webservers -i hosts.ini -m service -a "name=nginx state=started enabled=yes"

# 批量执行命令
ansible all -i hosts.ini -m shell -a "uptime"

    4.3 Playbook（可复用的剧本）

    下面这个 Playbook 完成「部署 Nginx 并配置健康检查页面」：

    # deploy_nginx.yml
---
- name: 部署 Nginx Web 服务器
  hosts: webservers
  become: yes            # 提权到 root
  tasks:
    - name: 安装 Nginx
      yum:
        name: nginx
        state: present

    - name: 写入健康检查页面
      copy:
        content: "ok"
        dest: /usr/share/nginx/html/health
        mode: '0644'

    - name: 启动并设置开机自启
      service:
        name: nginx
        state: started
        enabled: yes

    - name: 验证服务
      uri:
        url: http://localhost/health
        return_content: yes
      register: result
      until: result.content == "ok"
      retries: 5
      delay: 2

    执行：

    ansible-playbook -i hosts.ini deploy_nginx.yml
    幂等性是 Ansible 的灵魂

    Ansible 的模块（如 yum、service、copy）都是幂等的： 同样的 Playbook 执行多次结果一致，已安装的不会重复装，已启动的不会重复启动。 这让它非常适合配置管理和持续部署。

    本章小结

    • Shell 适合命令编排，注意变量空格、条件判断语法和引号区别。
    • 日志清理、健康检查、批量操作是 Shell 三大高频场景。
    • Python 用 subprocess 调命令、psutil 看资源、paramiko 做远程、requests 调 API。
    • Ansible 用 YAML 描述任务，SSH 免密，幂等执行，是批量自动化首选。
